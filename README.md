# Лабораторна робота № 14-15. Розробка Pet-проєкту (Team Project)

## Мета роботи

Набути практичних навичок, безпосередньо затребуваних на сучасному ринку праці в сфері розробки на Python. Навчитися розробляти невеликі, але функціонально завершені проєкти (так звані «Pet-проєкти»), використовуючи популярні бібліотеки, фреймворки та інструменти. Робота буде сфокусована на командній взаємодії, плануванні, застосуванні гнучких методологій розробки (Agile, Scrum), використанні систем контролю версій, а також написанні чистого, тестованого та документованого коду, готового до потенційного розширення та підтримки.

## Командна взаємодія

Ця лабораторна робота передбачає командну роботу. Вам необхідно сформувати команди по 3-4 особи. Успіх вашого проєкту залежить від ефективної комунікації, чіткого розподілу завдань та взаємодопомоги.

## Етапи виконання проєкту

### Етап 1. Вибір та обґрунтування Pet-проєкту

Ваша команда повинна провести дослідження ринку та визначити актуальні напрямки в розробці на Python. На основі цього дослідження оберіть ідею для свого Pet-проєкту.

**Завдання:**
1.  Проаналізуйте ринкові тренди.
2.  Оберіть ідею для проєкту (можна скористатися списком нижче).
3.  Обґрунтуйте свій вибір: визначте цільову аудиторію, потенційну користь та технічну складність.
4.  Заповніть відповідний розділ у файлі [`REPORT.md`](REPORT.md).

### Етап 2. Планування розробки та розподіл завдань

Після затвердження теми проєкту, детально сплануйте процес розробки.

**Завдання:**
1.  Розбийте проєкт на окремі задачі (створіть User Stories або Tasks).
2.  Оцініть час на виконання кожної задачі.
3.  Розподіліть завдання між членами команди.
4.  Налаштуйте цей репозиторій для спільної роботи (наприклад, створіть гілки для кожного учасника або для кожної фічі).
5.  Використовуйте інструменти для управління проєктом (наприклад, GitHub Projects, Issues).
6.  Заповніть відповідний розділ у файлі [`REPORT.md`](REPORT.md).

### Етап 3. Розробка та тестування

На цьому етапі ваша команда реалізує проєкт.

**Завдання:**
1.  Пишіть чистий, зрозумілий та добре документований код, дотримуючись стандартів **PEP 8**.
2.  Ведіть розробку ітераційно, регулярно тестуючи функціонал.
3.  Активно використовуйте Git для контролю версій: створюйте гілки, робіть змістовні коміти, використовуйте Pull Requests для об'єднання коду.
4.  Напишіть **unit-тести** для ключових частин вашого проєкту.
5.  Весь вихідний код проєкту розміщуйте в директорії [`src`](src/).

### Етап 4. Підготовка документації та презентації

Після завершення розробки, підготуйте документацію та презентацію.

**Завдання:**
1.  Опишіть основний функціонал проєкту.
2.  Створіть інструкції з встановлення та запуску вашого проєкту.
3.  Якщо ваш проєкт має API, задокументуйте його.
4.  Підготуйте презентацію для захисту проєкту.
5.  Оновіть фінальну версію звіту у [`REPORT.md`](REPORT.md).

### Етап 5. Захист проєкту

На останньому етапі ваша команда захищає проєкт. Захист включає демонстрацію роботи проєкту, презентацію та відповіді на питання.
